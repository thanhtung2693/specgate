Quick answers

Can green tests miss a requirement?

Yes. The suite can pass while the agreed 503 case has no test result.

What does it actually check?

Review agent claims, recorded check exit codes, and selected tests found in the observed reports. You decide whether the evidence is enough.

Do I need the browser UI?

The Local CLI records the scope, evidence, and decisions. Run specgate ui if you want to review and decide in a browser.
